# ===================================================
# Mathematical Background
# ===================================================

The Hayashi quantized Weyl algebra in n variables is generated by:

    Position operators:     x_1, ..., x_n
    Differential operators: dx_1, ..., dx_n
    Weight operators:       g_1, ..., g_n and their inverses

with defining relations (for each i, j):

    g_i * g_i^{-1} = 1 = g_i^{-1} * g_i
    g_i * g_j = g_j * g_i
    g_i * x_i = q * x_i * g_i
    g_i * dx_i = q^{-1} * dx_i * g_i
    g_i * x_j = x_j * g_i          (i != j)
    g_i * dx_j = dx_j * g_i        (i != j)
    x_i * x_j = x_j * x_i
    dx_i * dx_j = dx_j * dx_i
    dx_i * x_j = x_j * dx_i        (i != j)
    dx_i * x_i = q * x_i * dx_i + g_i^{-1}

From these relations one derives:

    x_i * dx_i = (g_i - g_i^{-1}) / (q - q^{-1})
    dx_i * x_i = (qg_i - (qg_i)^{-1}) / (q - q^{-1})

# ===================================================
# Usage
# ===================================================

Interactive Session
-------------------

Start Python interactively. In the terminal, type

    python -i <path-to>/hayashi_weyl.py

or, if you have hayashi_weyl installed, type

    python
    >>> from hayashi_weyl import HayashiAlgebra
    >>> # ... and so on

Basic Setup
-----------

    # Create algebra with 2 variables (default names: x1, x2, dx1, dx2, g1, g2)
    A = HayashiAlgebra(2)

    # Extract generators
    x1, x2 = A.x[1], A.x[2]
    dx1, dx2 = A.dx[1], A.dx[2]
    g1, g2 = A.g[1], A.g[2]
    g1inv, g2inv = A.ginv[1], A.ginv[2]
    q = A.q

Custom Variable Names
---------------------

    # Create algebra with custom names
    A = HayashiAlgebra(3, 
        x_names=['x', 'y', 'z'], 
        dx_names=['dx', 'dy', 'dz'], 
        g_names=['gx', 'gy', 'gz']
    )

    x, y, z = A.x[1], A.x[2], A.x[3]
    dx, dy, dz = A.dx[1], A.dx[2], A.dx[3]
    gx, gy, gz = A.g[1], A.g[2], A.g[3]
    q = A.q

Arithmetic Operations
---------------------

    # Multiplication
    result = g1 * x1 * g1inv
    print(result)  # q*x1

    # Addition and subtraction
    expr = dx1*x1 - q*x1*dx1
    print(expr)  # g1^-1

    # Powers
    print(x1**3 * dx1**2)

    # Scalar multiplication
    print(q**2 * x1 * dx1)

    # Commutator [A, B] = A*B - B*A
    print(A.comm(dx1, x1))

    # Anticommutator {A, B} = A*B + B*A
    print(A.anticomm(dx1, x1))

PBW Basis
---------

The algebra uses a preferred Poincaré-Birkhoff-Witt (PBW) basis. All elements
are expressed as linear combinations of monomials of the form:

    x_1^{a_1} * ... * x_n^{a_n} * dx_1^{b_1} * ... * g_1^{e_1} * ... 

where a_i, b_i >= 0 are non-negative integers and e_i are integers (can be negative).

That is, all x's come first, then all dx's, then all g's. Products are automatically
reordered to this form using the defining relations.

We use the full_reduce function to eliminate products x_i * dx_i and dx_i * x_1 using:

    x_i * dx_i = (g_i - g_i^{-1}) / (q - q^{-1})
    dx_i * x_i = (qg_i - (qg_i)^{-1}) / (q - q^{-1})

Simplify Output
---------------

Simplify coefficients for cleaner display:

    print(A.pretty(A.full_reduce(some_expression)))

    # Or call .simplify() directly on an element
    print(result.simplify())

# ===================================================
# Examples
# ===================================================

Example 1: Verify defining relation
-----------------------------------

    A = HayashiAlgebra(1, x_names=['x'], dx_names=['dx'], g_names=['g'])
    x, dx, g, ginv, q = A.x[1], A.dx[1], A.g[1], A.ginv[1], A.q

    # Check: dx*x - q*x*dx = g^{-1}
    print(dx*x - q*x*dx)  # g^-1

Example 2: Weight action
------------------------

    A = HayashiAlgebra(1, x_names=['x'], dx_names=['dx'], g_names=['g'])
    x, dx, g, ginv, q = A.x[1], A.dx[1], A.g[1], A.ginv[1], A.q

    # g * x * g^{-1} = q * x
    print(g * x * ginv)  # q*x

    # g * x^3 * g^{-1} = q^3 * x^3
    print(g * x**3 * ginv)  # q^3*x^3

Example 3: Two-variable commutator
----------------------------------

    A = HayashiAlgebra(2)
    x1, x2 = A.x[1], A.x[2]
    dx1, dx2 = A.dx[1], A.dx[2]
    q = A.q

    result = A.comm(x1*dx2, x2*dx1)
    print(A.full_reduce(result))
    # Output: (q/(q**2 - 1))*g1*g2^-1 + (-q/(q**2 - 1))*g1^-1*g2
